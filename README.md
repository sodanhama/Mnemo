# Mnemo
## Description
A web app to enable efficient learning through AI assisted spaced repetition through flashcards.

I developed a Cloudfare worker to fetch AI responses using HackClub AI for this project, and used Firebase's firestore database to implement the sm2 algorithm to create and review flashcards.

I also used Firebase for the sessions tab.
